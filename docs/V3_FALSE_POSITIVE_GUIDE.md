# 🛡️ AhnLab V3 백신 오탐지(False Positive) 정밀 분석 및 해결 가이드

본 문서는 **AhnLab V3** 백신에서 Grid IP Scanner2 다운로드 또는 실행 시 발생하는 **`Trojan/Win.Generic.C*` 오진(False Positive)** 현상의 기술적 원인, 사용자 PC에서의 즉각적인 해결 방법, 그리고 안랩 공식 화이트리스트 등록 절차를 상세히 안내합니다.

---

## 📸 1. 검출 현상 및 로그 정밀 분석

### 실제 검출 로그
```text
날짜: 2026-10-17 09:30:50
진단명: Trojan/Win.Generic.C5651299
파일 경로: C:\Users\user\AppData\Local\Google\Chrome\User Data\Profile 6\Cache\Cache_Data\f_00085a
```

### 왜 크롬 캐시(`f_00085a`) 경로에서 감지되었는가?
* 크롬(Chrome) 브라우저에서 웹 사이트, Google Drive, GitHub 릴리스 등에서 실행 파일(`.exe`) 또는 설치 파일(`.zip`)을 다운로드할 때, 브라우저는 먼저 로컬 사용자 캐시 디렉터리(`AppData\Local\Google\Chrome\...\Cache_Data\f_xxxxxx`)에 파일 스트림을 임시 기록합니다.
* 파일 기록이 완료되는 순간, **AhnLab V3의 실시간 파일 감시 모듈(Real-time File Monitor)**이 해당 임시 파일을 가로채어 클라우드 기반 검사를 수행하였고, 휴리스틱 엔진에 의해 **`Trojan/Win.Generic.C5651299`**로 잠정 분류하여 즉시 격리/삭제 조치한 것입니다.

## 🔍 2. V3가 네트워크 스캐너를 오진하는 핵심 원인

### ① `Trojan/Win.Generic.C*`의 본질 (AhnLab Smart Defense ASD)
`Trojan/Win.Generic.C*`는 특정 악성코드 고유 시그니처가 아니라, **AhnLab의 클라우드 평판/휴리스틱 분석 시스템(ASD: AhnLab Smart Defense)**이 새로 발견된 미지의 실행 파일에 대해 부여하는 **휴리스틱 가진단 코드**입니다.

### ② 네트워크 진단 도구의 소켓 동작 특성
* Grid IP Scanner2는 254개 전체 C-Class 서브넷을 초고속으로 탐색하기 위해 수백 개의 고속 비동기 TCP/UDP/ARP 소켓을 동시에 생성합니다.
* 상용 백신 엔진의 관점에서, 짧은 시간 내에 대량의 IP와 포트에 무차별 접속을 시도하는 행위는 **네트워크 웜(Worm)이나 정찰 트로이목마(Reconnaissance Malware)**의 침투 행위와 기술적으로 매우 유사하여 휴리스틱 점수가 급상승합니다.

### ③ 신규 빌드 바이너리 및 공인 EV 코드사인 부재
* 방금 컴파일된 신규 빌드 파일은 전 세계에 배포된 이력이 없어 V3 ASD 클라우드 평판 데이터베이스에 '신뢰(Trust) 점수'가 쌓여있지 않습니다.
* 테스트용 자가 서명(Self-Signed Certificate)은 개발자 로컬 PC의 인증서 저장소에서만 유효할 뿐, AhnLab V3 클라우드 서버 입장에서는 글로벌 공인 CA(DigiCert, Sectigo 등)의 상용 인증서가 아니므로 '미서명/미인증' 파일과 동일하게 평가됩니다.

## ⚡ 3. 사용자 PC에서 1분 만에 즉각 해결하는 방법

### 방법 A: V3 실시간 검사 예외 등록 (권장)
1. Windows 작업 표시줄 우측 트레이에서 **AhnLab V3 아이콘**을 더블 클릭하여 실행합니다.
2. 메인 창 우측 상단의 **톱니바퀴 아이콘 (환경설정)**을 클릭합니다.
3. 좌측 메뉴에서 **[검사 예외 설정]**을 선택합니다.
4. **[폴더 추가]**를 클릭하고 다음 경로를 예외로 지정합니다:
   - 설치 기본 경로: `C:\Program Files\Grid IP Scanner2\`
   - (필요 시) 다운로드 폴더: `C:\Users\<사용자명>\Downloads\`
5. **[파일 추가]**를 클릭하고 프로그램 실행 파일을 직접 등록합니다:
   - `Grid_IP_Scanner2.exe`
   - `Grid_IP_Scanner2_v2.4.3_Setup.exe`
6. 하단의 **[적용]** 및 **[확인]**을 누르면 이후 차단 없이 원활하게 실행됩니다.

### 방법 B: V3 격리소에서 차단된 파일 복원
1. V3 메인 화면에서 하단 **[보안 센터] > [로그]**를 클릭합니다.
2. 상단 탭에서 **[격리소]**를 선택합니다.
3. 2026-10-17 09:30:50에 격리된 `Grid IP Scanner2` 관련 파일(또는 `f_00085a`)을 선택합니다.
4. **[복원]** 버튼을 클릭하고, **"앞으로 이 파일을 검사에서 제외합니다"** 체크박스에 체크한 후 확인을 누릅니다.

### 방법 C: Chrome 브라우저 다운로드 보관
1. 크롬에서 다운로드 차단 경고가 뜨면 키보드에서 `Ctrl + J`를 눌러 다운로드 목록으로 이동합니다.
2. 차단된 파일 항목 우측의 **[위험한 파일 보관]** 또는 **[계속 다운로드]**를 클릭하여 정상 저장합니다.

## 🏛️ 4. 안랩(AhnLab) 공식 오진 신고 및 영구 해제 (화이트리스트 등록)

소프트웨어 개발자 및 공급자가 안랩 공식 신고 창구에 오진 해제를 요청하면, **AhnLab 분석관이 바이너리를 검증한 후 24~48시간 이내에 대한민국 전체 V3 최신 엔진에서 오진을 완전히 해제(화이트리스트 등록)**해 줍니다.

### 안랩 공식 오진 신고 센터 접수 절차
1. **신고 접수 URL**:
   👉 [AhnLab 고객지원 - 악성코드 / 오진 신고 센터](https://www.ahnlab.com/ko/support/virus-report)
2. **신고 분류 선택**:
   - `[오진 신고]` (정상 소프트웨어이나 악성코드로 오진됨)
3. **입력 정보 작성 예시**:
   - **프로그램 명**: Grid IP Scanner2 (v2.4.3)
   - **진단명**: `Trojan/Win.Generic.C5651299`
   - **개발사/작성자**: AhBiYout (www.cisnet.co.kr)
   - **프로그램 용도**: "사내 네트워크 관리자 및 엔지니어를 위한 정상 C클래스 IP/포트 스캔 및 OUI 하드웨어 분석 진단 도구"
   - **상세 내용**:
     ```text
     안녕하세요. Grid IP Scanner2 개발팀입니다.
     본 프로그램은 개인정보 탈취, 원격 제어, 악성 페이로드가 전혀 없는 순수한 사내 네트워크 관리 및 IP 스캐너 유틸리티입니다.
     신규 빌드 파일 배포 시 짧은 시간 내 포트 스캔을 수행하는 네트워크 소켓 특성으로 인해
     AhnLab V3 실시간 감시에서 'Trojan/Win.Generic.C5651299'로 오탐지(False Positive)되고 있습니다.
     첨부된 바이너리의 정밀 분석 및 V3 ASD 클라우드 엔진 화이트리스트 등록을 요청드립니다.
     ```
4. **파일 첨부 시 주의사항**:
   - 대상 파일(`Grid_IP_Scanner2.exe` 또는 `Grid_IP_Scanner2_v2.4.3_Setup.exe`)을 zip 압축합니다.
   - 백신 메일 서버의 차단을 방지하기 위해 압축 시 암호를 `infected` 또는 `1111`로 설정하고 신고 내용에 암호를 기재합니다.
5. **결과 피드백**:
   - 통상 영업일 기준 1일 이내에 분석 완료 이메일이 회신되며, 익일 V3 정기 엔진 업데이트에 정식 화이트리스트로 반영됩니다.

## 🛠️ 5. 개발팀 차원의 빌드 최적화 조치 (v2.4.3 반영 완료)

오진율을 사전에 최소화하기 위해 이번 업데이트에서 다음 빌드 조치를 완료하였습니다:

1. **`-trimpath` 컴파일러 플래그 전면 적용**:
   - Go 빌드 시 개발자의 로컬 파일 시스템 절대 경로(`C:\Users\user\...`)가 실행 파일 내부에 남지 않도록 스트립하여 백신의 임시 폴더 패턴 오탐을 원천 차단했습니다.
2. **Windows PE Manifest 완전 표준화 (`winres.json`)**:
   - `requireAdministrator` 정식 UAC 레벨 명시, 회사명(`AhBiYout`), 제품명(`Grid IP Scanner2`), 저작권, 설명 메타데이터를 PE 리소스에 완전하게 내장하여 정상적인 소프트웨어 프로필을 갖추었습니다.
3. **인스톨러 스텁 단일화 및 Inno Setup 권장**:
   - 수십 년간 전 세계 백신사에서 안전성이 검증된 Inno Setup 공식 컴파일러를 통해 인스톨러를 제작함으로써 Go 임베디드 셋업 대비 백신 오진율을 최소화했습니다.
