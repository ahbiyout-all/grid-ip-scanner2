1. 본문

안녕하세요, AhBiYout입니다.

네트워크 관리자, 시스템 엔지니어, 학교·사내 전산 담당자라면 한 번쯤 Advanced IP Scanner나 Angry IP Scanner 같은 진단 도구를 사용해 보셨을 것입니다. 하지만 기존 도구들은 수백 개의 IP 주소를 단순한 텍스트 행(Row) 리스트로만 나열하여 전체 네트워크의 유휴 공간과 밀도를 직관적으로 파악하기 어려웠습니다. 또한 학교·캠퍼스 네트워크에서 게이트웨이(.254)와 다른 IP(.251)가 동일한 L3 스위치 MAC으로 응답할 때 무조건 IP 충돌 경보로 오인하거나, 최근 스마트폰의 사설 랜덤 MAC(LAA) 기능으로 인해 장비 제조사조차 식별하지 못하는 한계가 있었습니다.

이러한 현장의 실질적인 문제를 해결하기 위해 탄생한 『Grid IP Scanner2』 (v2.5.0)는 C클래스(/24) 전체 254개 IP를 16x16 매트릭스 그리드 맵으로 실시간 시각화하며, OUI 시맨틱 다중 신호 기기 분류 & LAA 랜덤 MAC 역추적, 게이트웨이 Proxy-ARP 정상 판별 및 Proxy-ARP 인디케이터 뱃지 분리, 순수 창작 grid_topology_guard.dll (v2.6.1)과 IOCP·비동기 ICMP 고속 배치 스위프를 포함한 12대 네이티브 C/C++ DLL 엔진, UPnP/mDNS 실제 완제품 제조사 정밀 판별, Close-to-Tray 24/7 무인 침입 감시, 4색 스냅샷 Diff 비교, 원클릭 A4 규격 보안감사 PDF 출력을 제공하는 차세대 올인원 네트워크 스캐너입니다.

🚀 Grid IP Scanner2 핵심 기능

  • 16x16 시각화 그리드 맵: 전체 254개 노드의 활성/비활성/충돌/Proxy-ARP/Diff 상태를 신호등처럼 1초 만에 직관적으로 조망.
  • 🧠 OUI 시맨틱 다중 신호 분류 & LAA 랜덤 MAC 역추적: MAC OUI뿐만 아니라 개방 포트, mDNS, UPnP XML을 복합 점수화하여 IoT, CCTV, 가상머신(QEMU/Docker/VirtualBox/Hyper-V), 스마트 TV, 라우터를 자동 분류하고 신뢰도 점수 및 판별 근거를 투명하게 표기.
  • 🟦 게이트웨이 Proxy-ARP 비알림 분리 (Proxy-ARP 뱃지): 학교·기업망 L3 스위치 Proxy-ARP 또는 HSRP/VRRP 가상 게이트웨이(VIP)의 동일 MAC 다중 IP 응답은 붉은 충돌 경보(⚠️)가 아닌 스카이블루 Proxy-ARP 정보 뱃지로 깔끔히 분리해 오경보를 차단.
  • ⚡ 12대 순수 C/C++ 네이티브 DLL 엔진 & 보안 하드닝: 순수 창작 grid_topology_guard.dll(O(N) FNV-1a 토폴로지 해시), 비동기 ICMP/ARP 배치 스위프(Probe_SweepCidrAsyncBatch), Win32 IOCP 다중 호스트 포트 스위프(PortScan_IocpMultiHostSweep), GVAULT11 16B 솔트 PBKDF2-HMAC-SHA256 AES-256-GCM 암호화 및 DLL 경로 고정(LOAD_LIBRARY_SEARCH_APPLICATION_DIR) 탑재.
  • 📡 UPnP/SSDP XML & mDNS 실제 제조사 병기: 단순 칩셋 브랜드(Murata, Realtek 등) 대신 실제 완제품 브랜드(Samsung, LG, Apple, Synology 등)와 칩셋 OUI를 나란히 병기.
  • 🛡️ Close-to-Tray & 24/7 Windows 무인 백그라운드 서비스: 상단 닫기([X]) 버튼 클릭 시 창만 트레이로 숨기고 24시간 침입 감시와 정기 자동 스캔 스케줄러를 무중단 가동, 레거시 OS 긴급 스캔·DNS 플러시·방화벽 복원 서브메뉴 지원.
  • 📋 원클릭 IP 주소 복사 & 4색 스냅샷 Diff: 상세 프로필 원클릭 IP 복사, 신규 접속(+NEW)·오프라인(-OFF)·변동(!CHG)·유지(=SAME) 1:1 대조 스튜디오 및 A4 보안감사 PDF 리포트 출력.

2. 업데이트 (v2.5.0 최신 릴리즈 하이라이트)

  • 🧠 OUI 시맨틱 다중 신호 분류 & LAA 랜덤 MAC 역추적 엔진 탑재 (services/ouiClassifier.ts):
    • 단일 OUI 문자열 일치를 넘어 포트·mDNS·UPnP 복합 점수로 기기 유형(IoT/CCTV/VM/스마트 TV/라우터)을 정밀 분류합니다.
    • 랜덤 MAC(LAA) 장비도 mDNS/호스트명/포트 지문으로 교차 역추적하며 상세 패널에 신뢰도 점수(Confidence)와 판별 근거(Evidence)를 표시합니다.
  • 🟦 게이트웨이/인프라 Proxy-ARP 비알림 분리 및 UI 전용 Proxy-ARP 뱃지 신설 (conflictDetector.ts, IPCell.tsx, App.tsx):
    • 학교·캠퍼스 환경의 .251/.254 동일 MAC 다중 IP 등 게이트웨이 L3 Proxy-ARP 응답을 isGatewayProxyArp / 비알림 Info(isAlert = false)로 하향 판별하고 스카이블루 Proxy-ARP 인디케이터 뱃지로 시각화했습니다.
    • 일반 소비자 공유기·NAS 브랜드(asus, synology, qnap)는 화이트리스트에서 제외하여 실제 악성 MAC 복제 경보는 100% 포착합니다.
  • ⚙️ 순수 창작 grid_topology_guard.dll (v2.6.1) 및 IOCP / Async ICMP 배치 · Vault 보안 하드닝:
    • O(N) FNV-1a 해시 서브넷 델타·Proxy-ARP 판별 API(Guard_AnalyzeSubnetTopologyEx, GUARD_ANOMALY_INFRA_PROXY_ARP) 및 POST /api/topology-guard 엔드포인트를 연동했습니다.
    • Probe_SweepCidrAsyncBatch(단일 공유 ICMP 핸들 64-이벤트 윈도우 + 8스레드 ARP)와 PortScan_IocpMultiHostSweep(Win32 IOCP + ConnectEx) 고성능 배치 스위프를 신설했습니다.
    • 12대 DLL 경로 고정, GVAULT11 PBKDF2-HMAC-SHA256 256B 스택 고속 경로, 중첩·음수 포트 방어 JSON 파서 및 Deep Audit 동시성 결함 10종을 일괄 수정했습니다.
  • 📌 Close-to-Tray 하이브리드 수명주기 정상화 (v2.4.47 반영):
    • Go 단독 실행 파일 하트비트 단절 시 프로세스가 종료되던 결함 및 Electron before-quit 가로채기 버그를 해결해 창 닫기 시 완벽하게 트레이로 최소화됩니다.
