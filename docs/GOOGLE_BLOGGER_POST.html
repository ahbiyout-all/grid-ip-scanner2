[무료/초고속] 16x16 시각화 그리드 · 자율 시스템 트레이(동적 배지/방해금지/SCM 서비스) · Proxy-ARP 분리 · 12대 네이티브 DLL 엔진을 탑재한 차세대 네트워크 스캐너: Grid IP Scanner2 (v2.5.0)

1. 본문

안녕하세요, AhBiYout입니다.

네트워크 관리자, 시스템 엔지니어, 학교·사내 전산 담당자라면 한 번쯤 Advanced IP Scanner나 Angry IP Scanner 같은 진단 도구를 사용해 보셨을 것입니다. 하지만 기존 도구들은 수백 개의 IP 주소를 단순한 텍스트 행(Row) 리스트로만 나열하여 전체 네트워크의 유휴 공간과 밀도를 직관적으로 파악하기 어려웠습니다. 또한 학교·캠퍼스 네트워크에서 게이트웨이(.254)와 다른 IP(.251)가 동일한 L3 스위치 MAC으로 응답할 때 무조건 IP 충돌 경보로 오인하거나, 창을 닫으면 24시간 감시와 예약 스캔이 멈춰버리고 불필요한 알림이 반복되는 불편함이 있었습니다.

이러한 현장의 실질적인 문제를 해결하기 위해 한층 더 진화한 『Grid IP Scanner2』 (v2.5.0 · 2026-11-18 최신 개편판)는 C클래스(/24) 전체 254개 IP를 16x16 매트릭스 그리드 맵으로 실시간 시각화하며, Go 자율 시스템 트레이(동적 4색 배지 아이콘 · --tray 조용한 시작 · Windows SCM 네이티브 서비스 --service · 스케줄러 일시정지/즉시 실행 · 쿨다운/방해금지(DND) 이벤트 알림), OUI 시맨틱 다중 신호 기기 분류 & LAA 랜덤 MAC 역추적, 게이트웨이 Proxy-ARP 정상 판별 및 Proxy-ARP 인디케이터 뱃지 분리, 12대 네이티브 C/C++ DLL 엔진, 그리고 통합 보고서 센터(PDF·Excel·CSV·JSON·Markdown·HTML)를 모두 제공하는 차세대 올인원 네트워크 스캐너입니다.

🚀 Grid IP Scanner2 핵심 기능

  • 16x16 시각화 그리드 맵: 전체 254개 노드의 활성/비활성/충돌/Proxy-ARP/Diff 상태를 신호등처럼 1초 만에 직관적으로 조망.
  • 📌 Go 자율 시스템 트레이 & Windows SCM 서비스 (--tray / --service):
    • 동적 4색 배지 아이콘: 대기(회색), 24/7 감시(에메랄드), 스캔 중(호박색), 침입·충돌 경보(적색) 상태별 32×32 ARGB HICON 실시간 전환 및 요약 툴팁.
    • 창 없는 조용한 시작(--tray) & 무인 자율 감시: Windows 부팅 시 창 없이 트레이로 즉시 상주하며, 창이 닫혀 있어도 10초 주기 자율 스윕과 만기 예약 스캔을 지속 실행.
    • 트레이 빠른 제어 & Windows SCM 서비스(--service): 우클릭 메뉴에서 빠른 스캔, 24/7 감시 토글, 정기 스케줄러 일시정지/재개 및 즉시 실행을 제어하고 GridIPScannerService 상태(실행/중지/미설치)를 실시간 동기화.
    • 스마트 이벤트 OS 알림 (중복 억제 · 방해금지 DND): 신규 침입, IP/MAC 충돌, 대량 호스트 오프라인 급감 발생 시에만 OS 풍선 알림을 송출하며, 동일 이벤트 쿨다운 중복 억제와 상시/30분 일시 해제/야간 조용한 시간 지원.
  • 🧠 OUI 시맨틱 다중 신호 분류 & LAA 랜덤 MAC 역추적: MAC OUI뿐만 아니라 개방 포트, mDNS, UPnP XML을 복합 점수화하여 IoT, CCTV, 가상머신(QEMU/Docker/VirtualBox/Hyper-V), 스마트 TV, 라우터를 자동 분류하고 신뢰도 점수 및 판별 근거를 투명하게 표기.
  • 🟦 게이트웨이 Proxy-ARP 비알림 분리 (Proxy-ARP 뱃지): 학교·기업망 L3 스위치 Proxy-ARP 또는 HSRP/VRRP 가상 게이트웨이(VIP)의 동일 MAC 다중 IP 응답은 붉은 충돌 경보(⚠️)가 아닌 스카이블루 Proxy-ARP 정보 뱃지로 깔끔히 분리해 오경보를 차단.
  • ⚡ 12대 순수 C/C++ 네이티브 DLL 엔진 & 보안 하드닝: 순수 창작 grid_topology_guard.dll(O(N) FNV-1a 토폴로지 해시), 비동기 ICMP/ARP 배치 스위프(Probe_SweepCidrAsyncBatch), Win32 IOCP 다중 호스트 포트 스위프(PortScan_IocpMultiHostSweep), GVAULT11 16B 솔트 PBKDF2-HMAC-SHA256 AES-256-GCM 암호화 및 DLL 경로 고정(LOAD_LIBRARY_SEARCH_APPLICATION_DIR) 탑재.
  • 📄 통합 보고서 센터 & 4색 스냅샷 Diff 스튜디오: PDF(Zero Row-Chopping)·다중 시트 Excel·CSV·JSON·Markdown·HTML 내보내기, 원클릭 IP 복사 및 1:1 스냅샷 비교를 전용 모달 중심으로 깔끔하게 통합.
