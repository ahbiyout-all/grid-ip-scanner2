1. 본문

안녕하세요, AhBiYout입니다.

네트워크 관리자, 시스템 엔지니어, 학교·사내 전산 담당자라면 한 번쯤 Advanced IP Scanner나 Angry IP Scanner 같은 진단 도구를 사용해 보셨을 것입니다. 하지만 기존 도구들은 수백 개의 IP 주소를 단순한 텍스트 행(Row)으로만 나열해 전체 대역의 유휴 공간·L2 스위치 연결 구조·단말별 과거 접속 변동 이력을 파악하기 어려웠습니다. 또한 /22·/20 같은 확장 서브넷을 스캔하거나 여러 대의 PC를 한 번에 원격 부팅(WoL)·점검하고, 노트북부터 고해상도 모니터까지 편안한 글자 크기로 조절하며 관제하기에는 한계가 있었습니다.

이러한 현장의 실무 요구를 한 번에 해결하기 위해 대폭 진화한 『Grid IP Scanner2』 (v2.7.0 · 2026-11-26 최신 마이너 릴리즈)는 16x16 매트릭스 그리드 · 고밀도 테이블 · 3계층 인터랙티브 토폴로지 맵 · 4색 스냅샷 Diff v2 4종 통합 뷰를 제공할 뿐만 아니라, 가변 CIDR(/20–/30, 최대 4,094 호스트) 확장 스캔, 단말별 접속·포트 변동 이력 타임라인 DB, SNMP v2c 스위치 포트 및 L2 물리 연결 매핑(RAM 전용 볼트), 다중 단말 일괄 WoL/원격 제어 큐, 85%~130% 앱 전체 UI 통합 글자 배율 조절, 네이티브 패킷 정밀 텔레메트리(grid_pcap_analyzer.dll v2.6.2), 다중 서브넷 & VLAN 통합 대시보드, Go 자율 시스템 트레이 & Windows SCM 서비스, 그리고 12대 네이티브 C/C++ DLL 엔진을 모두 제공하는 차세대 올인원 네트워크 엔지니어링 스캐너입니다.

🚀 Grid IP Scanner2 핵심 기능

  • 🗺️ 4대 통합 워크스페이스 뷰 (Grid | Table | Topology Map | Snapshot Diff): 16x16 그리드 맵으로 대역 상태를 1초 만에 조망하고, 정렬·검색·일괄 체크박스 선택에 특화된 고밀도 테이블 뷰(DeviceTableView)와 3계층 줌/팬 SVG 토폴로지 맵·4색 스냅샷 Diff v2를 원클릭 전환하며 Pro 티어에서 grid_topology_guard.dll 연계 보안 상관분석 오버레이 제공.
  • 🌐 가변 CIDR (/20–/30, 최대 4,094 호스트) 확장 스캔 & 세그먼트 블록 분할: 기존 고정 /24 범위를 넘어 /30부터 초대형 /20 대역까지 자동 계획·청킹 스캔하며, 상단 CidrBlockBar에서 256 호스트 /24 블록 탭을 즉시 전환 (Free ≤/23, Pro /22, Enterprise /21–/20).
  • 📜 단말별 접속·포트 변동 이력 타임라인 DB (DeviceTimelineTab): Go 로컬 영속 시계열 저장소(timeline_events.jsonl)에 FIRST_SEEN, ONLINE, OFFLINE, IP_CHANGED, PORT_OPENED, PORT_CLOSED, VENDOR_OR_HOST_UPDATED, SWITCH_PORT_MOVED 8종 이벤트를 자동 기록하고 CSV 감사 내보내기 지원 (Free 24시간/50건, Pro 30일, Enterprise 무제한).
  • 🔌 SNMP v2c 스위치 포트 & L2 물리 연결 매핑 (SnmpSwitchConfigModal): Pure-Go IF-MIB/BRIDGE-MIB/Q-BRIDGE-MIB/LLDP-MIB 탐색과 디스크·스토리지에 절대 남지 않는 RAM 전용 자격증명 볼트로 단말의 스위치 포트·VLAN 연결을 자동 매핑하고 토폴로지 L2 링크·테이블·보고서에 통합 표기 (Pro 최대 2대 / Enterprise 무제한).
  • ⚡ 다중 단말 일괄 WoL 및 원격 제어 큐 (BatchQueueDrawer): 그리드 Ctrl/Cmd+Click 또는 테이블 체크박스로 여러 장비를 선택해 일괄 매직 패킷(WoL)·일괄 Ping·원격 포트 점검을 비동기 작업 큐로 실행하며, 동시 워커(1–4)·패킷 지연(100–2000ms)·중단·실패 재시도 지원 (Pro 16대 / Enterprise 무제한).
  • 🔍 앱 전체 통합 글자 확대·축소 (85%~130%, 5% 단위 · 100% 초기화): 상단 헤더 바(데스크톱·모바일)와 장치 상세 프로필 패널 상단에 동기화된 [ - | 100% | + ] 배율 컨트롤을 제공하며 Ctrl/Cmd + +/-/0 단축키로 즉시 조절 (A4 리포트 미리보기·인쇄·SVG 토폴로지 배율 격리).
  • 🔬 네이티브 패킷 텔레메트리 & Listening Ports 빠른 연결 (QuickConnectModal): 선택 호스트의 초기 TTL/추정 홉 수, TCP RTT/Jitter, OS 추정, Live ARP 스푸핑 검증을 원클릭 분석하고, Listening Ports 뱃지를 클릭해 SSH·RDP·HTTP/HTTPS·SMB·RTSP 등 프로토콜 아이콘·URI 복사·원격 실행 제안.
  • 📊 Free 16×16 엑셀 그리드(.xls) & Pro 전체 보고서(5시트) + A4 PDF 센터: Free 에디션은 16×16 엑셀 그리드 시트(Grid_16x16) 전용 .xls 및 일반 범위 CSV·JSON·Markdown·PDF를 무료 생성하며, Pro / Enterprise는 요약·그리드·장비 인벤토리·보안 감사·스냅샷 Diff까지 수록된 5시트 전체 보고서 엑셀 통합문서(.xls) 및 A4 스마트 페이지네이션 PDF 보안 감사 보고서(Zero Row-Chopping) 출력.
  • 📌 Go 자율 시스템 트레이 & Windows SCM 서비스 (--tray / --service) + Proxy-ARP 분리: 4색 동적 ARGB 배지 아이콘, 창 없는 시작(--tray), 10초 무인 자율 스윕, 쿨다운·방해금지(DND) 이벤트 OS 알림, 캠퍼스/기업망 게이트웨이 Proxy-ARP 스카이블루 뱃지 분리 및 OUI 시맨틱 LAA 랜덤 MAC 역추적 제공.
