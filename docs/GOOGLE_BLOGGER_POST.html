1. 본문

안녕하세요, AhBiYout입니다.

네트워크 관리자, 시스템 엔지니어, 학교·사내 전산 담당자라면 한 번쯤 Advanced IP Scanner나 Angry IP Scanner 같은 진단 도구를 사용해 보셨을 것입니다. 하지만 기존 도구들은 수백 개의 IP 주소를 단순한 텍스트 행(Row) 리스트로만 나열하여 전체 네트워크의 계층 연결 구조와 유휴 공간을 직관적으로 파악하기 어려웠습니다. 또한 여러 VLAN/서브넷을 오가며 스캔할 때 이전 결과가 덮어써지거나, 개별 호스트의 TTL/홉 수·TCP 핸드셰이크 지연(RTT/Jitter)·실시간 ARP 스푸핑 여부를 별도 패킷 분석기 없이 곧바로 확인하기 어려운 불편함이 있었습니다.

이러한 현장의 실질적인 문제를 해결하기 위해 한층 더 진화한 『Grid IP Scanner2』 (v2.6.0 · 2026-11-20 최신 마이너 릴리즈)는 C클래스(/24) 전체 254개 IP를 16x16 매트릭스 그리드 맵과 3계층 인터랙티브 토폴로지 맵으로 실시간 시각화할 뿐만 아니라, 네이티브 패킷 정밀 텔레메트리(grid_pcap_analyzer.dll v2.6.2), 다중 서브넷 & VLAN 통합 대시보드(로컬 NIC/VLAN 자동 탐색 및 대역별 캐싱), Free 티어 5시트 엑셀 그리드(.xls) & 최대 2개 서브넷 무료 개방, Go 자율 시스템 트레이 & Windows SCM 서비스, OUI 시맨틱 분류 & Proxy-ARP 비알림 분리, 그리고 12대 네이티브 C/C++ DLL 엔진을 모두 제공하는 차세대 올인원 네트워크 스캐너입니다.

🚀 Grid IP Scanner2 핵심 기능

  • 🗺️ 16x16 시각화 그리드 맵 & 3계층 인터랙티브 토폴로지 맵 (Grid | Topology Map | Snapshot Diff): 전체 254개 노드의 상태를 1초 만에 조망하고, 게이트웨이/코어 라우터 ➔ 인프라·Proxy-ARP·보안 그룹 ➔ 단말 노드 계층을 줌/팬 SVG 맵으로 시각화하며 Pro 티어에서 grid_topology_guard.dll 연계 보안 상관분석 오버레이 제공.
  • 🔬 네이티브 패킷 정밀 텔레메트리 (grid_pcap_analyzer.dll v2.6.2, /api/packet-inspect): 장치 상세 프로필 패널에서 원클릭으로 TTL/초기 TTL/추정 홉 수, TCP 핸드셰이크 RTT(Min/Avg/Max/Jitter), Window 힌트, OS 추정 신뢰도, Live ARP MAC 정합성을 실시간 분석.
  • 🌐 온디맨드 다중 서브넷 및 VLAN 통합 대시보드 (MultiSubnetBar, MultiSubnetModal, /api/subnets/discover):
    • 평소에는 깔끔한 단일 대역 화면을 유지하다 상단 다중 서브넷·VLAN(VLAN) 활성화 버튼 클릭 시 즉시 표시되며, 활성 VLAN Tag ID 인디케이터(활성 태그 + 프로파일별 컬러 VLAN 태그 마커)로 세그먼트 망을 한눈에 식별합니다.
    • 로컬 물리/가상/VPN/VLAN NIC 대역을 자동 탐색해 원클릭 등록하고, 대역별 독립 스캔 결과를 캐싱해 무손실 전환(Free 최대 2개 대역 무료).
    • Pro(최대 5개 대역) 및 Enterprise(무제한)에서는 순차 일괄 스윕(Batch Sweep) 및 교차 서브넷 이상 징후 통합 대시보드 가동.
  • 📊 Free 5시트 엑셀 그리드(.xls) & 통합 보고서 센터: 16x16 IP 그리드 맵 시트를 포함한 5시트 다중 시트 Excel XML(.xls), CSV, JSON, Markdown을 Free 에디션에서 무료로 내보내고, Pro 티어에서 A4 최적화 PDF 보안 감사 보고서(Zero Row-Chopping) 및 1:1 스냅샷 Diff 대조 제공.
  • 📌 Go 자율 시스템 트레이 & Windows SCM 서비스 (--tray / --service): 4색 동적 ARGB 배지 아이콘, 부팅 시 창 없는 조용한 시작(--tray), 10초 무인 자율 스윕, 스케줄러 일시정지/즉시 실행, 쿨다운·방해금지(DND) 이벤트 OS 알림 지원.
  • 🟦 게이트웨이 Proxy-ARP 비알림 분리 & OUI 시맨틱 LAA 역추적: 캠퍼스/기업망 L3 스위치 Proxy-ARP 동일 MAC 응답을 스카이블루 Proxy-ARP 뱃지로 분리해 오경보를 차단하고, OUI+포트+mDNS+UPnP 복합 점수로 LAA 랜덤 MAC 기기를 정밀 식별.
