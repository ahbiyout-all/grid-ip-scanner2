# Grid IP Scanner2 - Patch Note (v2.4.6)

## 🚀 [v2.4.6] - 2026-10-21

### 🌟 주요 기능 추가 및 안정화 (Major Improvements & Fixes)

1. **장치 프로필 패널 가독성 전면 개선 및 2단계 폰트 확대 시스템 탑재 (`App.tsx`)**
   - **극소 폰트(8~9.5px) 퇴출 및 표준 가독성 규격화**:
     - 기존 장치 프로필 패널에서 눈 피로를 유발하던 극소 폰트(8~9.5px)를 10~12px로 전면 상향 조정하고, IP 주소·MAC·제조사·호스트명·OS 등 핵심 데이터를 `text-sm`(14px) 굵은 글씨로 또렷하게 표시합니다.
   - **사이드바 최적 너비 확보 (`md:w-88 xl:w-96` / `shrink-0`)**:
     - 가로폭을 기존 320px에서 352~384px(확대 시 최대 420px)로 넉넉히 확장하여 텍스트 줄바꿈 없이 깔끔하게 수납되며, 메인 그리드는 고유의 1:1 종횡비 수학 공식(`max-w-[min(800px,calc(100vh-...))]`)에 의해 레이아웃 깨짐이 전혀 발생하지 않습니다.
   - **원클릭 글자 크기 전환 스위처 (`가 100%` ↔ `가⁺ 115%`)**:
     - 장치 프로필 헤더에 원터치 폰트 확대 버튼을 추가하여 필요 시 즉시 115% 확대 모드로 전환할 수 있으며, 설정값은 브라우저에 자동 영구 보존됩니다.

2. **스냅샷 기준색과 추가 스캔(+NEW) 노드의 시각적 대비 및 빈 셀 오분류 전면 개편 (`services/diffEngine.ts`, `IPCell.tsx`, `App.tsx`)**
   - **빈 IP 슬롯(245개)의 비정상 `= 변화 없음` 분류 버그 원천 해결**:
     - 기준점과 현재 모두 장비가 없는 미할당 빈 IP 슬롯(245개)이 `diffMap`에서 `same`으로 잘못 분류되어, 실제 기준 장비가 8대뿐임에도 `= 변화 없음: 253`으로 왜곡 표시되던 결함을 완벽히 수정했습니다.
     - 미할당 IP 슬롯은 `diffMap` 및 카운터에서 완전히 제외되어 그리드 배경으로 깔끔하게 디밍(`opacity-20`) 처리되며, 실제 온라인 상태인 기준 장비 수(예: 8대)만 정직하게 카운트됩니다.
   - **신규 추가 스캔 장비(+NEW)의 압도적 시각 강조**:
     - 새로 추가 탐지된 장비는 생동감 넘치는 에메랄드 그린 발광 효과, 펄스 애니메이션 핑 닷(`animate-ping`), 고대비 굵은 테두리(`ring-2 ring-emerald-400`), 명확한 `+ 신규` 배지로 최우선 부각됩니다.
   - **4대 스냅샷 기준색(하늘, 보라, 청록, 회색)의 고대비 금속 메탈 질감 강화**:
     - 기존에 어두운 배경색에 묻혀 보이지 않던 회색(`slate`)을 비롯한 4개 기준색 모두에 고대비 2중 테두리와 `= 기준` 배지, 견고한 메탈릭 배경 톤을 적용하여 어떤 색상을 선택해도 신규 장비 및 빈 셀과 즉시 구분됩니다.
   - **Diff 제어 툴바 범례 재정비**:
     - `추가 스캔 탐지: +신규(NEW)`와 `스냅샷 기준 장비: =기준(BASE)`의 2대 축을 명확한 색상 배지로 상단에 상시 표시하고, 4개 기준색 스위처(`하늘`, `보라`, `청록`, `회색`)의 활성 선택 테두리를 강화했습니다.

2. **스냅샷 비교 툴바 상단 내용 잘림 원천 해결 (Zero-Clipping Sub-Header Pinning)**
   - **독립 서브헤더 레이어 승격 (`App.tsx`)**:
     - 기존 Diff 진단 패널이 스크롤 본문 컨테이너(`overflow-y-auto`) 내부에 종속되어 있어, 그리드 렌더링이나 화면 크기에 따라 최상단 조작 버튼과 기준점 선택기가 헤더 뒤로 숨겨져 잘리던 구조적 결함을 완벽히 해결했습니다.
     - Diff 제어 툴바를 메인 `<header>` 직하단의 독립적인 고정 서브헤더 레이어(`border-b z-20 shrink-0`)로 승격하여, 어떤 스크롤 동작이나 뷰포트 크기에서도 상단 내용이 100% 온전히 유지됩니다.

2. **하단 중복 설명 상자 전면 영구 제거 (UI 클린화)**
   - 사용자 요청("하단에 설명 제거")에 따라 불필요하게 세로 높이를 낭비하던 하단 안내 텍스트 상자(`diffEmptyDesc`)를 완전히 삭제했습니다.
   - 불필요한 군더더기 요소를 없애고 데이터와 핵심 컨트롤에만 집중할 수 있는 깔끔한 전문가용 인터페이스로 정돈했습니다.

3. **초고밀도 2행 통합 툴바 & 단일 뷰포트 수납 (`calc(100vh - 190px)`)**
   - **1행 (제어)**: Diff 상태 식별기, 기준점 스냅샷 선택 드롭다운, 현재 상태 즉시 캡처 버튼, **1:1 대조 스튜디오 (Studio)** 실행 버튼, 가이드 및 그리드 복귀 버튼.
   - **2행 (진단/범례)**: 신규(+NEW), 오프라인(-OFF), 장비변경(!CHG), 변화없음(=SAME) 실시간 4종 카운터 버튼, 인라인 색상 범례 및 원클릭 기준 색상 스위처(하늘색, 보라, 청록, 회색).
   - 그리드 높이 예산을 `calc(100vh - 190px)`로 최적화하여 툴바와 16x16 그리드(256 노드) 전체가 스크롤 없이 한 화면에 시원하게 표시됩니다.

4. **스냅샷 비교 방법 전면 개편: 딥 다각도 비교 엔진(Deep Diff v2) 및 스튜디오 모달 완성 (`services/diffEngine.ts`, `components/SnapshotDiffModal.tsx`)**
   - **자유로운 임의 2개 시점 교차 비교**:
     - 기존의 라이브 스캔 ↔ 단일 스냅샷 종속 비교의 한계를 극복하고, 보관된 임의의 스냅샷 2개 간(스냅샷 A vs 스냅샷 B) 또는 실시간 스캔과의 자유로운 교차 대조 및 1클릭 소스 맞바꿈(Swap)을 지원합니다.
   - **보안 및 다각도 심층 변동 진단 (Deep Vector Analysis)**:
     - 단순 On/Off뿐만 아니라 **MAC 주소 변경(동일 IP 충돌/ARP 스푸핑 경보)**, **신규 개방 포트(+Port) 및 고위험 포트(21, 23, 445, 3389 등) 노출 경보**, **호스트명/제조사 변경**, **RTT 지연시간 급변**을 자동 감지합니다.
   - **1:1 Side-by-Side 시각적 대조 스튜디오**:
     - 전체 변동 장치들을 한 화면에서 [기준점 A]와 [비교점 B]의 상태, MAC, 포트를 나란히 대조할 수 있는 직관적인 비교 테이블과 실시간 검색/필터를 제공합니다.
   - **보고서 내보내기 & 텍스트 요약 복사**:
     - 변동 내역을 엑셀 CSV 파일로 원클릭 저장하거나, IT 보고용 서식 텍스트로 클립보드에 즉시 복사할 수 있습니다.

5. **스냅샷 비교 시 동일 장비 오탐지(False Positive) 원천 해결 및 별칭(Alias) 독립성 보장**
   - **사용자 별칭(별명/메모)의 완전한 독립성**:
     - 사용자 정의 기기 별칭은 로컬 스토리지에 격리 저장되는 UI 표시용 라벨이므로, 스냅샷 비교 변동(!CHG) 조건에 일체 관여하지 않음을 명문화하고 스튜디오 테이블에 별칭 태그(`🏷️ [별칭]`)를 직관적으로 연동했습니다.
   - **핑 지연시간 편차 디커플링 (Latency Decoupling)**:
     - Wi-Fi 또는 일시적인 트래픽 지연으로 인한 핑 편차(예: 2ms ➔ 55ms)만으로는 노드가 절대 `!CHG (장비 변경)`로 승격되지 않도록 수정했습니다.
     - 변동(!CHG)은 오직 **MAC 주소 변동(IP 충돌), 호스트명 변경, 제조사 변경, 개방 포트 추가/삭제** 등 실제 물리적·논리적 장비 정보가 바뀌었을 때만 트리거됩니다.
   - **MAC 및 호스트명 정규화 (Normalization)**:
     - MAC 구분자(`:`, `-`) 및 영문 대소문자 차이를 정규화하여 표기 방식 차이에 의한 오탐을 방지했습니다.
     - mDNS `.local` 접미사 및 임시 플레이스홀더('Unknown Device', 'Hidden Node', '-')는 정규화 필터를 거쳐 동일 장비로 정확히 대조합니다.

6. **스캔 중 브라우저 창 닫기/새로고침 방지 경고 및 스캔 안전 중지 이벤트 탑재 (`beforeunload` & `pagehide`)**
   - **이탈 방지 경고**: 스캔이 진행되는 동안 브라우저 창을 닫거나 새로고침(F5, Ctrl+R, 뒤로 가기)을 시도할 경우, 브라우저 표준 경고 팝업을 즉시 띄워 의도치 않은 작업 손실을 예방합니다.
   - **안전한 스트림 및 리소스 중단**: 사용자가 페이지 이탈을 확정할 경우 백그라운드 SSE 스트림(`AbortController.abort()`), 상태 플래그(`stopScanRef`), 렌더링 타이머를 즉각 정상 해제하여 소켓 누수와 불필요한 백엔드 부하를 방지합니다.

7. **기술 문서 `docs/SNAPSHOT_DIFF_SPEC.md` 공식 개정**
   - 차세대 딥 비교 판별 알고리즘, 고위험 포트 탐지 기준, 1:1 스튜디오 사양, 상단 잘림 방지 서브헤더 아키텍처 및 오탐 방지 규칙을 공식 명세화했습니다.
